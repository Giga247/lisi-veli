# QA-ჩექლისტი

გაირბინეთ **დეპლოირებულ მისამართზე** (`https://<username>.github.io/<repo>/`),
არა localhost-ზე — localhost `docs/setup.md`-ის დროებითი origin-ია და წაშლილი
იქნება. სამი ანგარიშით გასავლელი: **ადმინი**, **მოდერატორი**, **მაცხოვრებელი**.
სამივესთვის დაგჭირდებათ ცალკე Google ანგარიში (ან ბრაუზერის ცალკე პროფილი).

**კონსოლიდან შემოწმებისთვის:** გახსენით ბრაუზერის დეველოპერული კონსოლი
(Chrome-ში: მარჯვენა ღილაკი გვერდზე → Inspect → Console, ან `Cmd+Option+J`
Mac-ზე) საიტზე შესული მდგომარეობით. ქვემოთ მოცემული ბრძანებები პირდაპირ ამ
კონსოლში იწერება — `API` გლობალურია და მოქმედი მომხმარებლის ტოკენს იყენებს.
`await`-იანი ბრძანება პირდაპირ Enter-ით გაეშვება, პასუხი კონსოლში ჩანს.

## უფლებები

- [ ] მოდერატორი ცხრილში და რუკის ბარათზე ხედავს ✏️ ღილაკს
- [ ] მოდერატორს ადმინის ტაბი გვერდის თავში **არ უჩანს**
- [ ] მოდერატორი, კონსოლიდან: `await API.call('users')` → იჭერს შეცდომას,
      `error.code === 'FORBIDDEN'`
- [ ] მოდერატორი, კონსოლიდან, სცადეთ დაცული ველების შეცვლა — ოთხივე უნდა
      დაბლოკოს `FORBIDDEN`-ით და შეტყობინებით „ველი არ ექვემდებარება
      რედაქტირებას: …". ქვემოთ გამოყენებული `01.99.99.999.001` ბაზაში
      **რეალურად არსებული** ნაკვეთის კოდია — მას გეომეტრიაც აქვს და
      კოორდინატებიც, ანუ ოთხივე დაცული ველი მართლა მოწმდება —
      ბრძანებები პირდაპირ, უცვლელად იწერება კონსოლში. არარსებული კოდი
      `NOT_FOUND`-ს დააბრუნებდა, ველების თეთრი სია საერთოდ არ შემოწმდებოდა
      და პუნქტი ჩუმად აზრს დაკარგავდა:

  ```js
  await API.call('updatePlot', { cad: '01.99.99.999.001', expected_updated_at: '',
    fields: { geometry: '[[[0,0]]]' } })   // FORBIDDEN: geometry
  await API.call('updatePlot', { cad: '01.99.99.999.001', expected_updated_at: '',
    fields: { lat: '41.7' } })             // FORBIDDEN: lat
  await API.call('updatePlot', { cad: '01.99.99.999.001', expected_updated_at: '',
    fields: { lon: '44.7' } })             // FORBIDDEN: lon
  await API.call('updatePlot', { cad: '01.99.99.999.001', expected_updated_at: '',
    fields: { cad: '00.00.00.000' } })     // FORBIDDEN: cad
  ```

- [ ] მაცხოვრებელს (`member`) ✏️ ღილაკი **არ უჩანს** არც ცხრილში, არც რუკის
      ბარათზე
- [ ] მაცხოვრებელი, კონსოლიდან: `await API.call('updatePlot', { cad:
      '01.99.99.999.001', expected_updated_at: '', fields: { note: 'x' } })` →
      `FORBIDDEN` (მოქმედება საერთოდ არ აქვს ამ როლს, ველის ტიპს არა აქვს
      მნიშვნელობა)
- [ ] ადმინი, ადმინის პანელიდან, საკუთარ როლს `member`/`moderator`-ზე ცდილობს
      დაქვეითებას → „ბოლო ადმინის როლი ვერ შეიცვლება" (თუ ეს ერთადერთი
      ადმინია — ჩვეულებრივ ასეა)
- [ ] **ბოლო ადმინის დაცვა მუშაობს whitespace-იანი უჯრითაც.** Sheet-ის
      `მომხმარებლები` ფურცელში ადმინის `როლი` უჯრაში ჩაწერეთ `admin ` (სიტყვის
      ბოლოში გამოტოვება) → ადმინის პანელიდან სცადეთ ამ ადმინის დაქვეითება →
      მაინც დაბლოკილია: „ბოლო ადმინის როლი ვერ შეიცვლება". ტესტის შემდეგ
      უჯრა ისევ ზუსტად `admin`-ზე დააბრუნეთ (whitespace-ის გარეშე)
